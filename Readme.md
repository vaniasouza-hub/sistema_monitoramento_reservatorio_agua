# 📊 : Controle de Níveis de Água

Projeto desenvolvido em Python para monitoramento de um reservatório de água.
---

## 📌 Sobre o Projeto

O programa realiza uma coleta de dados do nível de água e, ao final, exibe o alerta de acordo com a criticidade de cada reservatório.
